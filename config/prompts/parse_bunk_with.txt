This field commonly contains:

2. "not_bunk_with" - Embedded negatives (look for "NOT", "don't", "please avoid", "separate from")

3. "age_preference" - Preference for older/younger cabinmates (no specific person named)
   target_name = "older", "younger", or "unclear"
   Use when text says "prefers older kids" without naming anyone specific

IMPORTANT: Parents often embed negative requests in this field. Extract BOTH positive and negative.

=== NAMED INDIVIDUALS ONLY ===

Every bunk_with / not_bunk_with request MUST name a specific individual camper.
Group references ("last year's bunkmates", "kids from her school", "friends
from synagogue", "the twins", "her siblings", "my twin") must NOT be expanded
into individual requests or assigned a guessed name — staff review is required.
See STAFF-REVIEW FALLBACK below.

=== STAFF-REVIEW FALLBACK (NEVER SILENTLY DROP) ===

If the text expresses a bunking preference but does NOT name a specific
individual, emit exactly ONE bunk_with (or not_bunk_with) request with:
- target_name = "" (empty string)
- needs_clarification = true

Unnamed group examples — each produces ONE staff-review record:
- "Bunk with last year's bunkmates" → 1 bunk_with, staff-review fallback
- "Last year bunkmates in Session 3 B-4" → 1 bunk_with, staff-review fallback
- "Kids from her school" / "schoolmates" / "from Park Day" → 1 staff-review fallback
- "Friends from synagogue" / "Beth Jacob girls" → 1 staff-review fallback
- "Same bunk as 2024" → 1 bunk_with, staff-review fallback
- "Her twin" / "siblings" / "my brother" (no name given) → 1 staff-review fallback

Never invent individual names, never split an unnamed group into multiple
requests. Staff sees the original text and decides.

=== SIBLING NAMING GUARDRAILS ===

The requester's last name is included in the requester info above.
- If a sibling/twin is named explicitly ("bunk with my twin Emma Johnson"),

- If a sibling/twin is referenced WITHOUT a name ("her twin", "my siblings"),
  use the staff-review fallback above.
- If two people are mentioned wanting to bunk together but have DIFFERENT last
